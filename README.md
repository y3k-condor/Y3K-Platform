## Как установить

**Доступен Y3K Update Manager 0.2.18 (Stable)** — отдельный компонент для управления обновлениями, интегрируемый в Wazuh Dashboard. **Сама Y3K Platform пока находится в разработке и не имеет публичного установочного пакета.**

| Канал | Назначение | Репозиторий |
| :--- | :--- | :--- |
| **Stable** | Проверенные версии Y3K Update Manager | [APT Stable](https://update.y3k.by/stable/apt/) |
| **Nightly** | Тестовые сборки для проверки перед Stable | [APT Nightly](https://update.y3k.by/nightly/apt/) |

Для установки Update Manager требуется подключить выбранный APT-канал, проверить доверенный ключ подписи репозитория и совместимость версии с установленным Wazuh Dashboard. **Не подключайте одновременно Stable и Nightly без явной политики выбора пакетов.**

> **Важно:** версия 0.2.18 опубликована в Stable, но её установка на Wazuh с существующими сторонними доработками пока не рекомендована: выявлена несовместимость защитных механизмов. Исправление готовится в 0.2.19. До публикации проверенной инструкции подключения ключа и APT source не копируйте команды из непроверенных источников. Публикация пакета в APT не означает, что он уже установлен на вашем сервере.

Проверенные команды подключения репозиториев и установки будут добавлены здесь после подтверждения адресов ключей, структуры APT и совместимости пакета. GitHub Releases и публикация пакетов в APT — разные механизмы; актуальный канал установки определяется подписанным APT-репозиторием.

## Концепция

ИТ-инфраструктура предприятия объединяет системы, ресурсы и сервисы, от которых зависит ежедневная работа. Y3K Platform развивается как единое рабочее пространство для их централизованного управления, мониторинга и контроля безопасности.

В центре проекта — целостное представление об инфраструктуре и понятный русскоязычный интерфейс. Безопасность является одним из ключевых направлений наряду с управлением и эксплуатацией ИТ.

## Направления развития

| Направление | Задача |
| :--- | :--- |
| Инфраструктура | Объединять представление о системах, ресурсах и сервисах предприятия |
| Управление | Формировать общее рабочее пространство для задач администрирования |
| Мониторинг | Делать состояние инфраструктуры и сервисов понятным для администратора |
| Безопасность | Включать контроль событий и защищённости в общую работу с инфраструктурой |

Эта таблица описывает концепцию и направления развития. Она не является перечнем реализованных функций, поддерживаемых интеграций или обязательством по срокам.

## Статус проекта

Y3K Platform находится в разработке; публичного дистрибутива Platform пока нет. Отдельный компонент Y3K Update Manager уже имеет Stable APT-публикацию. Подробные инструкции и подтверждённая совместимость будут дополняться по мере проверки.

Этот репозиторий — публичная витрина Y3K Platform: описание проекта и фирменные материалы.
